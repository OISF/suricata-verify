# Description

Workers must not time out flows bypassed with eBPF or XDP: only the flow manager
can ask the capture method whether such a flow is still active, collect its
counters and remove its entries from the eBPF maps.

The bypassed flows end before `flow-timeouts.tcp.bypassed` expires. New flows
that arrive after that timeout share the hash rows of the bypassed flows
(`flow.hash-size: 10`), which makes the workers evaluate these rows. All 100
bypassed flows have to be closed by the flow manager, as counted by
`flow_bypassed.closed`.

A flow closed by the flow manager must not be asked again when it is recycled:
that would show as "Unable to delete entry" warnings for its eBPF map entries.
