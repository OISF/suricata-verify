# Description

Packets and bytes of capture-bypassed flows that were not yet read from the
eBPF maps are accounted in `flow_bypassed.pkts` and `flow_bypassed.bytes` when
Suricata shuts down. The bypassed timeout is longer than the test, so the flow
manager does not read the counters before the shutdown. Both flows end at the
shutdown and are counted in `flow_bypassed.closed`.
