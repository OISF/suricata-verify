# Description

With XDP bypass and `pinned-maps: true` the entries of bypassed flows stay in
the pinned flow table when Suricata exits, but only for the flows that have not
reached `flow-timeouts.udp.bypassed`. A flow that timed out without new packets
is removed from the map at shutdown, also when the flow manager did not get to
it before the stop: nothing would remove its entries while Suricata is down.

40 flows are bypassed and time out 3 seconds before the end of the replay,
10 more are bypassed 1 second before the stop. The flow manager needs 10
seconds to go through the flow table (see suricata.yaml), so it has only
handled part of the 40 flows when Suricata is stopped.

After the run the pinned IPv4 flow table is dumped with bpftool: it has to hold
the 20 entries (one per direction) of the 10 flows that have not timed out. All
50 flows are counted in `flow_bypassed.closed`. The XDP filter and the pinned
maps are then removed from the test interface.
