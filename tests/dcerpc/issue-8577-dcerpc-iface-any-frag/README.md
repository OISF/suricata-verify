# dcerpc.iface any_frag: first fragment handling

## Purpose

Verify that the `any_frag` option of `dcerpc.iface` follows the Snort
`dce_iface` semantics: without `any_frag` the keyword only matches if the
REQUEST PDU has the `PFC_FIRST_FRAG` flag set. The flags of the BIND PDU are
not relevant. With `any_frag` the fragment flags are ignored. The request
decides for both directions, the flags of the RESPONSE PDU are not considered.

## PCAP

`input.pcap` is generated by `generate-pcap.py` (scapy). It contains 5 TCP
connections to port 135, each doing a BIND to a test interface
(`12345678-1234-abcd-ef00-01234567cffb` version 3.0), a BIND_ACK accepting
the interface, and one REQUEST / RESPONSE pair:

| Client port | BIND flags | REQUEST flags | RESPONSE flags |
|-------------|------------|---------------|----------------|
| 40001       | 0x00       | 0x03          | 0x03           |
| 40002       | 0x03       | 0x01 + 0x02   | 0x03           |
| 40003       | 0x03       | 0x00          | 0x03           |
| 40004       | 0x03       | 0x02          | 0x03           |
| 40005       | 0x03       | 0x03          | 0x02           |

## Expectations

- SID 1 (`to_server`, no `any_frag`): 40001, 40002, 40005.
- SID 2 (`to_server`, `any_frag`): all 5.
- SID 3 (`to_client`, no `any_frag`): 40001, 40002, 40005 (same as SID 1,
  response flags are not considered).
- SID 4 (`to_client`, `any_frag`): all 5.
- SID 5 / 6: interface version `=3` matches like SID 1, `>3` never matches.
- SID 7 / 8: a different interface UUID never matches.
