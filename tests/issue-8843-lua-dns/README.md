# Lua DNS OPT answer regression

This test covers Redmine issue 8843. It supplies a DNS response whose answer
section contains an OPT record with two EDNS options. The Lua DNS output calls
`tx:answers()` and records the combined `addr` value.

Before the fix, the OPT handler pushed the `addr` key and both option key/value
pairs, then called `lua_settable(-3)` only once. With two options this uses just
five additional stack slots, well below `LUA_MINSTACK`, but `-3` refers to an
option-data string instead of the answer table and Lua reports `attempt to index
a string value`. A fixed build returns the combined value `10:cookie 3:nsid`.

`input.pcap` is generated by `make-pcap.py` with Scapy.
