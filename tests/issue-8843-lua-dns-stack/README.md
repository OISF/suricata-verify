# Lua DNS OPT answer stack regression

This test covers the security impact of Redmine issue 8843. It supplies a DNS
response whose answer section contains an OPT record with 100 zero-length EDNS
options. The Lua DNS output calls `tx:answers()` and records a completion marker.

Before the fix, the OPT handler pushed two Lua strings per option without
balancing or growing the Lua stack. An ASAN build detects heap corruption while
handling the crafted response. A fixed build returns from `tx:answers()` and
writes the expected marker to `lua-dns.log`.

`input.pcap` is generated by `make-pcap.py` with Scapy.
