Reproducer for output-lua: every failed log() call leaves the error
object on the Lua stack. All seven output log callbacks run lua_pcall
and log the error without popping it, so a script that raises on every
event grows the shared output state without bound.

The script raises for the first 2000 DNS events, then measures live Lua
memory (after a full collectgarbage) at the end of the replay. With the
leak the leaked stack slots plus the leaked error strings show as
unbounded growth (~150KB); with the error popped per call the growth is
~0.

dns-flood.pcap is generated by create-pcap.py (2200 query/response
pairs).
