# Description

DNP3 log limits: object and point lists are cut at 64 and 256, string
fields at 8 KiB with an in-value marker, base64 fields at 8 KiB raw, and
the G70V2 password is not logged. See
https://redmine.openinfosecfoundation.org/issues/9372

# PCAP

Generated by `create-pcap.py`: one TCP flow with six application PDUs -
one object with 1000 points, 100 objects with one point each, G70V1
objects with a 9000-byte filename and a 9000-byte data field, a G70V2
object with username and password, and a G83V1 object with a 9000-byte
base64 payload. Validated with `tshark -r` (DNP 3.0 dissector).
