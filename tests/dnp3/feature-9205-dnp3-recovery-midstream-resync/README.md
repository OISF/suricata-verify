# Redmine feature 9205 — mid-stream pickup, start sequence past offset 0

A connection picked up mid-stream (`stream.midstream: true`) whose first packet
comes from the outstation and starts mid-frame: six octets without a start
sequence, then a response. With `resync-on-bad-start` on, protocol detection
finds the response's start sequence past offset 0 and applies the same
direction check as for a header at offset 0, so the outstation's frames are
parsed as responses and the master's as requests. `input.pcap` is generated by
`create-pcap.py`.
