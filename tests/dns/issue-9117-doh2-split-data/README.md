# DoH2 DNS inspection after delayed END_STREAM

Redmine #9117.

In each direction, a DATA frame carries the DNS message without END_STREAM,
then an empty DATA frame closes the stream. Both the query and the answer
must be inspected even when outer HTTP/2 prefilter engines run first.

The response-header alert remains checked on main only: the 8.0.x HTTP/2
header-inspection behavior differs on this traffic. The DNS query, DNS
answer, HTTP request and DoH2 flow checks apply to both branches.
