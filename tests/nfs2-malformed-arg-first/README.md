# nfs2-malformed-arg-first

The v2 request path wires file identity with the same last-transaction
event call v3 uses, so a malformed argument on the first record of a flow is
dropped. This fixture puts the malformed v2
LOOKUP first, which is the case that was silently lost.

Generated by `nfs2-malformed-arg-first.py`: v2 LOOKUP with 3 argument bytes
(a2FolderPath is a filename3), then a READLINK with a full 32 byte fhandle2,
each answered with NFS2ERR_NOENT. Over UDP: the TCP probe accepts only
program versions 3 and 4.
