# nfs3-malformed-handle-arg

Covers the bare-filehandle arm of the v3 request path (`nfs3.rs`, the
`parse_nfs3_handle` failure branch): READ, READLINK, READDIR, FSSTAT, FSINFO
and PATHCONF wire the handle so the record carries `hhash` and the resolved
name. When the argument cannot even hold the 4 byte handle length the parse
must fail with `malformed_data` rather than wire an empty handle.

`input.pcap` is generated by `nfs3-malformed-handle-arg.py`: a v3 READLINK
CALL with 2 argument bytes, followed by a well-formed GETATTR CALL so the
session is demonstrably live.
