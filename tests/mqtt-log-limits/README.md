# Description

MQTT log limits: long strings are cut with an in-value marker, the SUBACK
return-code list stops at 64, the UNSUBSCRIBE topic list stops at the
record topic budget, and CONNECT passwords are not logged by default.
See https://redmine.openinfosecfoundation.org/issues/9372

# PCAP

Generated by `create-pcap.py`: one MQTT v3.1.1 session with a 60000-byte
protocol string, a SUBACK carrying 100 return codes, a 2000-byte PUBLISH
payload and an UNSUBSCRIBE with two 1000-byte topics.
