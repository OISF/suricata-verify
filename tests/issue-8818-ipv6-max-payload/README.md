# Redmine #8818 IPv6 maximum payload boundary

Boundary regression for
https://redmine.openinfosecfoundation.org/issues/8818.

The pcap is generated by `make-pcap.py` with Scapy. It contains one IPv6 UDP
datagram split across 46 fragments. An 8-byte Destination Options header and
65,527 fragmentable bytes produce the maximum non-jumbo IPv6 payload of 65,535
bytes. Including the fixed IPv6 header, the reassembled packet is 65,575 bytes.

Vulnerable builds narrow that total packet length to 39 before the second IPv6
decode. They count the chain as reassembled but silently skip UDP and content
inspection.

The final bytes of the UDP payload contain a marker matched by `test.rules`.
This proves that the reassembled boundary packet reaches transport and content
inspection without its total packet length being narrowed to 16 bits.
