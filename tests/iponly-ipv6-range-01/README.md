# iponly-ipv6-range-01

## Purpose

To test that the rules match as expected against the traffic whose address
falls in the ipv6 range that is written in the rule.

## PCAP

Generated by `writepcap.py` (scapy): a single IPv6/ICMPv6 echo request,
`src=2001:db8::10`, `dst=2001:db8::ffff`, written with linktype RAW (101).
