# Description

PostgreSQL log limits: long startup parameter values and simple queries
are cut with an in-value marker, and a 300-message ParameterStatus burst
stops at the record message cap (`pgsql.truncated`). See
https://redmine.openinfosecfoundation.org/issues/9372

# PCAP

Generated by `create-pcap.py`: one PostgreSQL session with a
StartupMessage carrying two 1100-byte values, 300 ParameterStatus
messages and a 1200-byte simple query.
