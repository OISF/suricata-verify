# rdp-inner-incomplete

Verify that complete T.123 TPKTs whose inner payloads are malformed (an
X.223 class 0 data PDU with an empty payload, and a CS_CORE block claiming
more bytes than the TPKT contains) do not wedge the RDP app-layer parser.
Before the fix the inner Incomplete escaped `parse_t123_tpkt` and the
to-server RDP transactions after the poisoned TPKTs (X.224 connection
request, MCS connect request) were never parsed or logged.

The pcap is generated by `gen_pcap.py` (self-contained; the handshake
payloads are taken from `rdp-protocol/RDP-003.pcap`).
