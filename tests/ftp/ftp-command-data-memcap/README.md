# Description

Test `ftp.command_data` inspection when the FTP memcap rejects the request
buffer allocation. The transaction remains available for inspection with a
NULL request and a zero request length, which must be handled as an empty
inspection buffer rather than passed to the MPM.

Issue 8880.

# PCAP

The PCAP is generated by `make-pcap.py`. It contains a TCP handshake followed
by a `USER` command with a 4000-byte argument. The configured 1 KiB FTP memcap
allows the FTP state and transaction allocations but rejects the request
buffer allocation.
