# ruletype-firewall-545-tls-version-early-hook-13

A TLS 1.3 ClientHello fragmented across two TLS records. The first record
only carries the record layer/legacy version 0x0303 (TLS 1.2); the second
completes the `supported_versions` extension (0x0304). The `tls:client_started`
hook is evaluated before the hello is decoded, when only the legacy version is
visible.

`tls.version` is stateful and its match function only returns a final
no-match once the hello decoded (returning "revisitable" while it is not). The
rule therefore matches the negotiated 1.3 version on the packet that completes
`supported_versions` (frame 6, `ts_progress` `client_cert`). The legacy 1.2
value never matches.

Before the fix the early miss became final (P+1 `CANT_MATCH`) and the rule
never fired - a fragmentation evasion on the hook path.

The pcap is generated by `craft-pcap.py`.
