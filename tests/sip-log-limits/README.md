# Description

SIP log limits: the request line, uri and SDP string fields are cut at
8 KiB with an in-value marker, and the SDP `k=` encryption key is not
logged. See https://redmine.openinfosecfoundation.org/issues/9372

# PCAP

Generated by `create-pcap.py`: one UDP INVITE with a 9 KiB request uri,
a 20000 byte SDP session name and session/media `k=` lines.
